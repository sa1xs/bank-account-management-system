# Bank Account Management System

Java project developed for the first Object-Oriented Programming practice at Universidad CENFOTEC.

## Overview

The system models an administrator, clients, and three types of bank accounts: savings, debit, and credit.

## Features

- Register and list clients.
- Associate multiple bank accounts with each client.
- View account details, balances, and a consolidated account statement.
- Validate initial balances, account dates, credit limits, and passwords.
- Test the classes and their relationships in `Main.java`.

> **Note:** Banking operations such as deposits, payments, credit repayments, and interest calculation are declared but not yet implemented.

## Project structure

- `src/model/` — Java classes and `Main.java`.
- `docs/` — UML class diagram (`.drawio` and `.pdf`).

## How to run

Open the project in IntelliJ IDEA, configure a Java JDK, and run `src/model/Main.java`.
